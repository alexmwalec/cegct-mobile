System description

CEGCT Mobile lets community members report environmental problems such as illegal dumping, pollution, and unsafe waste disposal.
Each report carries a photo, GPS location, and short description, and receives a case number.
It works offline and syncs when the network returns. Users follow their case through a status timeline, get notified when authorities act, 
message the assigned officer, and confirm nearby reports to help verify them.
The app connects to the CEGCT web dashboard through a shared REST API.
